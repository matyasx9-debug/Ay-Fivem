# Security Policy

## Supported Versions

Security fixes are focused on the latest release of AY Developer Panel.

| Version | Supported |
| --- | --- |
| 2.x | Yes |
| < 2.0 | No |

## Reporting a Vulnerability

Please do not disclose security vulnerabilities in a public issue.

Instead, contact the repository owner privately through the GitHub profile or use GitHub's private vulnerability reporting if it is enabled for the repository.

When reporting a vulnerability, include:
- A clear description of the issue
- Steps to reproduce it
- The affected file or feature
- The potential impact
- A suggested mitigation, if known

Please do not include passwords, API keys, tokens, Discord webhooks, or other secrets in reports.

## Security Notes

AY Developer Panel performs server-side authorization checks for sensitive administrative actions. Server owners should still configure ACE permissions carefully and keep their FiveM artifacts and dependencies up to date.
